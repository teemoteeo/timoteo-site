# timoteo-site

Personal portfolio of Timoteo Costantini Scala, software developer and 42 Firenze student.

Live: https://teemoteeo.github.io/timoteo-site

Static site with no framework or build step: HTML, CSS and vanilla JavaScript, plus Three.js for the Rubik's cube. It has a terminal-style boot sequence and typing animations, and a hidden easter egg you open with the Konami code.

```
index.html
css/   base, layout, components, cube
js/    boot, ticker, konami, rubik2d, rubik3d, tech
```

Run locally: `python3 -m http.server` then open http://localhost:8000
