BUSY

A macOS menu bar app that measures how much of your day goes to work (green) and how much to distractions (red). A switch in the menu bar shows the current state at a glance, and one click opens the recap of the day. No timers to start: it watches the app in front and the site open in the browser.

install

  • Install: open the zip and drag BUSY.app into Applications.
  • First launch: BUSY isn't signed with a paid Apple Developer certificate, so macOS blocks it the first time. On macOS 15 and 26, open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. On macOS 14, right-click the app → Open → Open. Or, in Terminal:xattr -dr com.apple.quarantine /Applications/BUSY.app
  • Permissions: it only asks to control your browser, to read the domain of the active tab (revoke it in Privacy & Security → Automation). Your activity stays in ~/Library/Application Support/BUSY; the only network request fetches a site's icon from that site.
  • Is it safe? Scan the zip on VirusTotal. Check the code: upload the source of this exact version to Claude, ChatGPT or any model that reads files, with this prompt:

how it works

  • Classification: on every app switch the active app is matched by bundle ID. For Safari, Chrome and Arc it reads the URL of the active tab through AppleScript every 2.5 seconds and keeps only the domain, subdomains included.
  • Pauses: after 5 minutes without input, and during sleep, shutdown or user switch, tracking stops on its own, so idle time never counts as either colour.
  • Recap: day, week, month and year, with a red/green timeline of active time only and a top 10 of apps and sites. Any entry opens its own stats.
  • Rules: mark installed apps green or red, add a site by pasting a link. Changes apply instantly, past included, because the recap recolours the stored history with the current rules every time.
  • Local only: one SQLite file and one rules.json in Application Support. Your activity never leaves the Mac; the only network request fetches a site's icon from that same site.
  • Native: the menu bar switch is an NSStatusItem animated with Core Animation; the window uses the Liquid Glass sidebar on macOS 26 and still runs on macOS 14, Apple Silicon and Intel.
