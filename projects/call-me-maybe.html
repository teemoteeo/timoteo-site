call-me-maybe

Function calling with a 0.6B-parameter language model. The model turns a request in natural language into a JSON call with typed arguments. On its own a model this small doesn't reliably follow a schema. Here, at every generation step, every token that would break the JSON or the schema is masked out, so the output is valid by construction.

how it works

      
  • Grammar as DFA: numbers, strings (escapes and surrogate pairs included), booleans and function names each have their own automaton. A token is legal only if the automaton can consume all of it.
  • Precomputed masks: boolean masks over the whole vocabulary are cached per DFA state or accumulated prefix. Each step is then one mask lookup plus a vectorized argmax, never a scan of the vocabulary.
  • Skipping the model: once a name or literal is unambiguous, the rest is injected verbatim, and a step with only one legal token needs no forward pass.
  • Shared prefixes: for names like fn_add vs fn_add_numbers, the logits decide between closing the string and continuing it.
  • Guaranteed termination: near the step budget, the string grammar only accepts tokens that close the value, so every output file stays schema-valid.
